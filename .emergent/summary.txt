<product_requirements>
The user, a content creator for teachers who teach coding, requires an application to facilitate coding education.
**Core Functionality:**
- **Teacher-managed Classrooms:** Teachers create classrooms and invite students via class codes.
- **Assignment Creation:** Teachers (or content creator) input assignments with:
    - Instructions/description
    - Starter code (optional)
    - Solution code
    - Expected output (newly added)
    - Category, Difficulty, CSTA K-12 CS Standards (for content library)
- **AI-Powered Grading:** Students submit code; an AI evaluates it, providing a score (including partial credit) and feedback for Python code.
- **Output Window:** Students should see the output of their code execution.
- **Authentication:** Google social login for both teachers and students.
- **Programming Language:** Python only.

**Evolved Features & Enhancements:**
- **Gamification:**
    - **Lives System:** Students get 3 lives per assignment; a life is lost on failed submissions (< 70% score). Lockout after 3 failed attempts. Students must run code before submitting.
    - **XP & Coins:** Students earn XP for passing assignments (bonus for perfect score, first-try, streaks) and coins (per assignment, perfect score, daily login).
    - **Levels/Ranks:** 9 distinct ranks with associated XP ranges and themed visual styles.
    - **Virtual Shop:** Students spend coins on dashboard themes, profile badges, custom avatars/borders.
    - **Leaderboard:** Classroom-specific leaderboard displaying rank, name, XP, problems solved, streaks.
- **Content Management (Assignment Library):**
    - **Content Creator Role:** Upload pre-made Python assignments (instructions, starter code, solution code, test cases, PowerPoints, lesson plans, workbooks).
    - **Teacher Assignment Library:** Teachers browse, filter, search, and import ready-made assignments into their classrooms.
    - **Create Assignment Form:** Teachers can manually create single assignments.
    - **Bulk Upload:** Option to upload assignments via CSV.
    - **Multi-Problem Assignments (Planned Rebuild):** Bundle multiple individual problems from the library into a single assignment.
- **Scheduling & Assignment Control:**
    - **Multi-Class Assignment:** Assign problems/assignments to multiple classrooms simultaneously.
    - **Scheduler:** Set available (start) and due dates/times for assignments.
    - **Availability:** Assignment titles visible to students before , but inaccessible.
    - **Late Submissions:** Accepted after due date with a Late badge and optional penalty.
    - **Teacher Timezone:** Scheduling based on teacher's local timezone.
    - **Post Now Option:** Immediately make an assignment available.
    - **Classroom Default Start Times:** Define a default start time per classroom to auto-apply during scheduling.
- **Teacher Practice Sandbox:** An area for teachers to practice coding assignments before teaching.
- **Live Demo Mode:** Teachers can run starter code in front of the class.
- **Team Battles:** Classrooms can challenge each other, with winning based on average XP per student.
- **UI/UX:** Side-by-side code editor and output window with resizable panels.

**Problem Solved:** The platform aims to simplify coding instruction for teachers, allowing them to leverage pre-made content and AI grading, while engaging students through gamification and competition.
</product_requirements>
