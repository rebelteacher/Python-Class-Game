<product_requirements>
The ByteBattles Arena app is an educational platform for teachers to manage coding education. Key features include teacher-managed classrooms, assignment creation (instructions, code, output, category, difficulty), AI-powered Python grading, and Google social login. Evolved features include a gamified lives system, XP/Coins, ranks, and a student leaderboard. Content management focuses on a global problem library, bulk uploads, multi-problem assignments, and teacher editing. Teacher tools include a practice sandbox and a reports page for exporting student scores, completion dates, and tracking missing/incomplete assignments. Security involves removing student-side teacher options. Most recently, the user requested teacher-specific username/password login, an invite code system, and an admin dashboard for monitoring. Student-side issues include code persistence, per-problem lives, visual problem completion status, accurate XP/coins, and a working navigation. Library organization via chapters is also a new requirement.
</product_requirements>
